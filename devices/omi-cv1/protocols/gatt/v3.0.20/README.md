# Omi CV1 GATT profile: stock v3.0.20

[profile.json](profile.json) is the machine-readable service expectation derived from the pinned
production configuration and firmware source. It is not yet a dump from the owned device.

The Android read-only probe should normalize discovered UUIDs/properties/permissions, redact stable
device identifiers, and diff them against this profile. Differences are retained as evidence rather
than silently updated away.

Important limitations:

- Zephyr standard services and the MCU Manager service are generated by SDK modules, so their presence
  is inferred from the pinned build configuration and must be confirmed in the built ELF/GATT map and
  on the device.
- Native C integer values are little-endian on nRF5340. The current button payload is an ABI-shaped
  eight-byte `int[2]`; Gumi must not reuse that shape as a new cross-device protocol.
- `read`/`write` permissions in this profile are not encrypted/authenticated permissions. The stock
  custom characteristics do not require link security at the attribute layer.
